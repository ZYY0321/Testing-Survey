## 已有实验的评估（11-04）

上次汇报几乎没有动机性的发现，主要是实验设计的问题：问的是"别人的工具能不能发现 UX 问题"，可它们都不是为 UX 设计的；商业 App 上没有页面总数和缺陷标签；没有对照。

| 实验 | 评估 | 处理 |
|---|---|---|
| 第零步 R0–R7（复现 8 个工具） | 已完成；能用的是"它们怎么工作、在哪坏"的现象，回答不了 UX 相关的问题 | 停止新的复现；FuncDroid、HapTest、LLMDroid 留作探索基线；GraphDroid 她补写后复现 |
| UI-Lens（R7） | 数据现成，不用复现 | 停 |
| OS-Genesis、PropGen 新运行 | 和我们目标关系弱 | 停，学弟只写清"怎么做、能借鉴什么、问题在哪" |
| SE2-a 按状态类型算开合问题率 | 只能基于没复核的 GPT 标签；她判断问题没有预兆 | 并进 M4，在 mock 里用已知真值检验 |
| G-a 人工标 3 个 App 的功能页面 | 人工量大 | 改成 M5，mock 里 URL 就是标准答案 |
| AX-4 每一步都核验是否浪费 | 前提还没验证 | 暂停 |
| AX-2 macOS CUA | 公司那边的事 | 移出 |
| SE1-a 开合标签人工复核 | 必须做，所有开合数字都卡在这里 | 保留 |
