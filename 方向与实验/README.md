# 方向与实验

我们准备写的几篇论文的方向分析，和要先跑的验证实验。实验跑完，在 `待跑的实验.md` 对应小节末尾补结果，再回到 `方向分析.md` 在对应假设后面写"成立 / 不成立"。

| 文件 | 内容 |
|---|---|
| [方向分析.md](方向分析.md) | 四个方向（视觉问题检测、以 UX 问题为目标的探索、从轨迹长出功能状态图、结构树和画面对不上）各拆一篇范文：从动机到贡献、方法、实验怎么写；再对标我们，列出动机假设、贡献假设、要什么证据、对应哪个实验、什么结果就放弃 |
| [待跑的实验.md](待跑的实验.md) | 每个实验怎么做、几个人几天、放弃条件。**从"第零步"开始**：先把别人的开源工具（GraphDroid、FuncDroid、HapTest、LLMDroid、PropGen、OS-Genesis、ReFLAIR、UI-Lens 数据）跑起来 |
| [材料/开源工具可运行性核实.md](材料/开源工具可运行性核实.md) | 每个工具的仓库地址、依赖、README 里的运行命令、已知报错（2026-10-30 核实，均未在设备上实际跑过） |

范文的精读笔记在 [`../notes/`](../notes/)，审稿规律在 [`../reviews/`](../reviews/README.md)。
